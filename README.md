#  Sistema Reservei — Protótipo & Modelagem UI/UX

> Projeto acadêmico desenvolvido durante o semestre focado no processo completo de Design de Experiência do Usuário (UX) e Prototipagem (UI) para um sistema de gestão de reservas de restaurantes.

---

##  Visão Geral do Projeto

O **Reservei** nasceu da necessidade real de organização de reservas de mesas em restaurantes. O objetivo principal foi mapear as dores dos clientes e gestores, transformando requisitos complexos em uma interface simples, acessível e intuitiva.

Este repositório armazena a documentação técnica, artefatos de pesquisa e os links diretos para a arquitetura de informação e protótipo interativo.

---

## Mapeamento & Pesquisa (Miro)

Toda a fase de ideação, levantamento de requisitos e estrutura do produto foi documentada no Miro, contemplando:

- **Briefing & Benchmarking**
- **Matriz CSD** (Certezas, Suposições e Dúvidas)
- **Levantamento Quantitativo & Desk Research**
- **Personas & Entrevistas com Usuários**
- **Bullseye Framework**

 **[Acessar Board de Pesquisa no Miro](https://miro.com/app/board/uXjVGrZ39eA=/?share_link_id=985268310803)**
